## 核心功能

### 1. 自动催办
- 每天按配置的时间点（默认 09:30 / 14:00 / 17:00）自动读取文档并催办
- 仅工作日（周一到周五）执行
- 针对各部门负责人生成个性化催办消息，@对应人员
- 检测长期未更新的部门，发送更新提醒

### 2. AI智能风险评估
- 使用 Claude API 分析任务进度数据
- 自动识别：逾期任务、阻塞任务、进度异常、截止日临近但进度不足
- 风险分四级：`low` → `medium` → `high` → `critical`
- 内置规则引擎作为降级方案（AI不可用时自动切换）

### 3. 人工预警通知
- 当AI评估发现 `high` 或 `critical` 级别风险时，自动触发预警
- 通过钉钉群 ActionCard 消息 + 工作通知双通道通知管理者
- 预警包含：风险详情 + AI建议的干预措施

### 4. 领导看板与周报
- 每日自动生成结构化的进度看板（Markdown格式，钉钉群直接展示）
- 包含：整体概况表格、AI风险评估、各部门进度条、需关注事项
- 每周五自动生成周度趋势分析报告
- 报告底部标注 "AI智能任务跟踪系统自动生成"，体现AI赋能

## 你需要配合的事情

### 钉钉在线文档格式要求

请让各部门负责人按以下格式在钉钉在线文档中更新：

```
【市场部 - 张三】
更新时间: 3/18
1. Q2品牌推广方案 | 截止:3/25 | 进度:60% | 已完成线上渠道对接，线下物料制作中
2. 春季营销活动 | 截止:3/20 | 进度:85% | 方案已定稿，等待设计部出图
3. 竞品分析报告 | 截止:3/15 | 进度:40% | 延期，数据收集不完整

【技术部 - 李四】
更新时间: 3/17
1. 系统升级 | 截止:3/22 | 进度:75% | 核心模块已完成，测试中
2. 数据迁移 | 截止:3/18 | 进度:20% | 阻塞：需要DBA支持
```

**格式规范：**
- 部门标题用 `【部门名 - 负责人姓名】`
- 每个任务一行，用 `|` 分隔各字段
- 必填：任务名称、截止日期、进度百分比
- 选填：备注说明（越详细，AI分析越准确）
- 更新时间行可选，用于检测是否有部门长期未更新

### 钉钉配置步骤

1. **创建企业内部应用**（钉钉开放平台 → 应用开发 → 企业内部开发）
   - 获取 AppKey 和 AppSecret
   - 添加权限：在线文档读取、消息通知发送

2. **创建群机器人**
   - 在目标群 → 群设置 → 智能群助手 → 添加机器人
   - 安全设置选择"加签"，获取 Webhook 和 Secret

3. **获取文档信息**
   - 在钉钉文档链接中提取 docId 和 spaceId

4. **配置环境变量**
   - 复制 `.env.example` 为 `.env`，填入上述信息

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 填入钉钉和AI的配置

# 3. 运行测试
npm test

# 4. 启动服务（含定时任务）
npm start
```

## HTTP API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/health` | GET | 健康检查 |
| `/api/trigger` | POST | 手动触发一次完整催办流程 |
| `/api/analyze` | POST | 提交文档内容进行AI分析（不发送消息） |
| `/api/process` | POST | 提交文档内容并执行完整流程（分析+催办+预警） |
| `/api/status` | GET | 查看最新的任务数据和分析结果 |
| `/api/trends` | GET | 查看近N天的趋势数据 |

**示例：手动提交文档内容分析**
```bash
curl -X POST http://localhost:3000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"content": "【市场部 - 张三】\n1. 推广方案 | 截止:3/25 | 进度:60% | 正常推进中"}'
```

## 给领导展示的亮点

1. **全自动化运行**：系统7x24小时运行，工作日自动执行催办流程，无需人工操作
2. **AI深度分析**：不是简单的超时提醒，而是通过AI理解任务备注内容，评估真实风险
3. **智能预警机制**：只在真正需要人工介入时才通知管理者，避免信息过载
4. **数据驱动决策**：自动生成看板和周报，管理者可一目了然了解全局进展
5. **效率提升量化**：将原本每天30-60分钟的人工跟催、汇总工作自动化，每月节省约20小时
